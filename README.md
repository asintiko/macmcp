# mcpclaude

An MCP (Model Context Protocol) server for **remote cloud agents on macOS**. Run one command
in Terminal and a cloud AI agent — Claude or any other MCP client — can run shell commands,
work with files and drive the desktop of your Mac (screenshots, mouse, keyboard, windows,
menus), including creative applications such as Adobe After Effects and Blender.

> **Status:** under active development. See [docs/development/PLAN.md](docs/development/PLAN.md)
> for what is implemented and verified so far.
